==================================================
PROJECT OVERVIEW
==================================================
MacSite is a responsive web tribute dedicated to 
Mac Miller's complete album discography, spanning 
from his 2010 mixtape 'K.I.D.S.' to the posthumous 
release 'Balloonerism'. 

FEATURES:
- Album-specific CSS gradient borders for each album container
- Custom header image fading effect via CSS masking
- Mobile-first, responsive Flexbox layout
- Detailed release dates and trivia for each project

TECH STACK:
- HTML5
- CSS3 (Variables, Flexbox, Pseudo-elements)
- JavaScript
